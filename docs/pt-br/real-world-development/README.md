Explore o GitHub Copilot ao longo do ciclo de vida do desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar mudanças, criar código, testar comportamentos, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é um novo desenvolvedor na Tailspin Toys, uma empresa fictícia de financiamento coletivo de jogos de tabuleiro com tema de desenvolvimento. O backlog da equipe já está registrado como issues do GitHub e pronto para você escolher uma tarefa. Ele inclui recursos como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de programação.

## Escolher o ambiente

O GitHub Copilot acompanha você no ambiente de sua preferência. Escolha aquele que melhor corresponde à forma como quer desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado do Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, MCP do Playwright, Agent Merge e comandos de barra práticos.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne os modos de sessão, colabore em Canvas e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests abertos pelo agente.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
