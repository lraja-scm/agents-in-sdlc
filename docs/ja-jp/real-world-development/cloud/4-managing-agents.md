ここまでの演習で、Copilot クラウドエージェントにユーザー体験の向上と機能追加に関する 3 つのタスクを依頼しました。クラウドエージェントは非同期かつ自律的に動作しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクは、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールで管理できます。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行内容を調べ、進行中のセッションに追加の指示を与えて方向付けることもできます。

このレッスンでは、次のことを行います。

- エージェントページを使って、クラウドエージェントのタスクを監視します。
- 進行中のセッションに追加機能を依頼し、方向付けます。

## シナリオ

ハイコントラストモードの作成をエージェントに依頼した後、チームはライトモードも追加することにしました。サイトのスタイルと切り替え機能はすでに変更中なので、この機能も含めるのが自然です。エージェントの作業を方向付け、ハイコントラストに加えてライトモードも追加させます。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたすべてのタスクの現在の状態を確認します。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左側のペインに表示されるタスク一覧を確認します。Copilot に割り当てた、次のようなタスクが表示されます。
    - コードのドキュメントを更新する。
    - ゲームを変更するアプリケーションプログラミングインターフェイス (API) を生成する。
    - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを選択し、Copilot が行った作業を確認します。たとえば、次のような内容が含まれます。
    - リポジトリからコードをチェックアウトする。
    - Copilot が作業する環境を作成する。
    - モデルコンテキストプロトコル (MCP) サーバーをセットアップする。
    - 割り当てられたタスクを完了するための各種手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここでは PR と変更されたファイルを表示し、作業をさらに監視できます。

## クラウドエージェントに指示を追加する

進行中のタスクを確認したので、ハイコントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼します。

1. ハイコントラストモードの追加に関するセッションを選択します。表示されるタイトルは、Copilot が付けた名前や作業状況によって異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、Copilot が作業を始めたことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログに、次のプロンプトを入力します。

    ```plaintext
    ハイコントラストモードの作業に加えて、ライトモードも追加してください。利用者が希望する表示モードを選べるよう、このモード用の切り替えも用意してください。
    ```

    ![クラウドエージェントのタスク画面で、作業中のセッションに指示するダイアログが強調表示された状態](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業の流れに組み込んだことを確認します。

## Copilot の作業を続ける

これまでと同様に、Copilot は更新されたタスクに取りかかります。メッセージを送信した時点で実行していた手順が完了した後、新しい依頼を作業に取り込みます。

ここでも数分かかります。その間に、これまでに学んだ内容を振り返ってみましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウドエージェントのタスクを監視して方向付ける中心的な場所である、Copilot エージェントページを確認しました。このミッションコントロールで、進行中および完了したタスクを追跡し、実行中の作業を確認し、進行中のタスクに追加の指示を与えて範囲を調整できます。

次の内容を確認しました。

- ミッションコントロールとエージェントページでクラウドエージェントのタスクを監視しました。
- 進行中のセッションに追加機能を依頼しました。

Copilot がアクセシビリティ機能を実装している間に、次は Copilot が作成したプルリクエストを[反復して改善します][next-lesson]。
